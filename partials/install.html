Install

git clone git@github.com:mohamadKrayem/readyvim.git ~/personal/dotfiles
cd ~/personal/dotfiles
./install.sh

install.sh symlinks each config into the place its tool expects. Anything already sitting at one of those paths is moved into a timestamped ~/.dotfiles-backup-* directory first, so nothing of yours is overwritten. Re-running it is safe.

Try it without touching your own config

No symlinks, nothing written outside the clone:

git clone git@github.com:mohamadKrayem/readyvim.git ~/personal/dotfiles
XDG_CONFIG_HOME=~/personal/dotfiles nvim

NVIM_APPNAME won't work for this — it resolves under ~/.config, so it can't reach a clone living somewhere else.

Or in Docker

A throwaway container with all the tools, nothing installed on your machine:

make docker-test

Pin a version

git clone --branch v0.1.0 git@github.com:mohamadKrayem/readyvim.git ~/personal/dotfiles
