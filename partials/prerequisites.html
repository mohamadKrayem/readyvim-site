Prerequisites

Install these before running the setup. Most are already on a developer machine.

ToolWhy it's needed
Neovim 0.11+Uses vim.diagnostic.jump and vim.hl
git, ripgrep, fdTelescope pickers
a C compiler + makeBuilding treesitter parsers
nodeSeveral language servers
python3basedpyright, debugpy
tmux 3.2+Floating popups
fzfThe prefix + f project switcher
lfFile manager, and netrw's replacement
lazygit, yaziOptional — the integrations expect them if you use them

A Nerd Font is required for Neovim: the statusline, bufferline and diagnostic signs all use glyphs. The tmux config is deliberately ASCII-only and needs no special font.

Language servers and debug adapters install themselves through Mason the first time you open Neovim, so there's nothing to set up by hand.
