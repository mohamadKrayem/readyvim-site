Keymaps

A selection — the ones that shape how the setup feels. The full list is in the repo. Leader is Space.

Moving around

KeyDoes
Ctrl+h/j/k/lMove between Neovim splits and tmux panes, same keys
Ctrl+p / Ctrl+nJump 8 lines up / down
[[ / ]]Start / end of the construct the cursor is in (treesitter)
<leader>n / <leader>pNext / previous occurrence of the word under the cursor

Text objects

KeySelects
aq / iqA string with / without its quotes — any quote style, multi-line included
af / ifA function, outer / inner
ac / icA class, outer / inner

Files and projects

KeyDoes
<leader>-Open lf with the cursor already on the current file
<leader>sf / <leader>sgFind files / live grep
<leader>spSwitch project — saves this one's session, restores the next one's
<leader>sPBounce back to the previous project

tmux

KeyDoes
prefix + fPick a project, and open it as a session with editor and terminal side by side
prefix + Shift-TabBack to the last project
prefix + t / prefix + gFloating scratch shell / lazygit
prefix + - / prefix + _Split stacked / side by side

Inside lf

KeyCopies
yn / ysFile name / name without extension
yp / ydAbsolute path / containing directory
yrPath relative to the repo root

y is a prefix there, so lf's built-in copy is yy. af / ad create a file / directory, D deletes with a confirmation. Clipboard commands are macOS-only for now (pbcopy).
